# 🤖 Claude — AI Family Study Profile

**Developer:** Anthropic · **Origins:** 2023 · **Profile reviewed:** 9 November 2026

[← 15-model catalog](../MODEL-CATALOG.md) · [← AI Academy](../README.md)

> **Important distinction:** Proprietary assistant and model family. A consumer chatbot, underlying model, API and open-weight distribution are not necessarily the same product. Avoid comparing model families by marketing claims alone.

## 1. Where this AI came from

Anthropic publicly introduced Claude in March 2023, originally emphasizing conversational assistance and document work. [Official background](https://www.anthropic.com/news/introducing-claude).

## 2. What it does

**Typical applications:** Writing, code review, document reasoning and tool-assisted tasks.

**Current research note:** Check Anthropic model documentation for current Claude variants and availability; do not assume a model name remains constant. This page summarizes a model **family**; it does not claim a single version is universally best or list unsupported prices and benchmark rankings.

## 3. How a learner can use or investigate it

1. Open the [official entry point](https://claude.ai/) and check account requirements and access in your region.
2. Start with a **non-confidential** task, using a clear objective and an example.
3. Request a structured answer, assumptions, source links where available and uncertainty.
4. Check important claims against original sources; run code before trusting it.
5. Compare the result on the same task with another model family in the catalog.

**Lab exercise:** Give Claude a fictional 300-word project brief and request a summary, assumptions, unanswered questions and a fact-check checklist.

## 4. Technical questions

- Is the selected version proprietary, open-weight, or under a specific custom license?
- Is the model served online or deployable locally? What hardware and storage are required?
- Which modalities and tools does the **specific version** accept?
- What data retention, training-use, privacy and organizational settings apply?
- How are answers evaluated for factual accuracy, bias, reliability, latency and cost?
