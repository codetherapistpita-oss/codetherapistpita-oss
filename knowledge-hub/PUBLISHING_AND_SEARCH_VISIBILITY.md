# Publishing, Search Visibility & Live Updates — Roadmap

The Knowledge Hub is currently a public **GitHub Markdown documentation library**. It does not automatically publish live news, appear first in Google Search, or sync with Google Drive.

## Phase 1 — Reliable public reference library (implemented)

- Topic folders with clear names and index pages.
- Attributed published resources and separate empty indexes.
- Links from the GitHub profile to the Knowledge Hub and portfolio.
- Date- and source-aware publishing templates.

## Phase 2 — Public website and discoverability (not yet deployed)

- Build a dedicated static site using GitHub Pages or another supported host.
- Use descriptive page titles, clean page paths, accessible semantic HTML, responsive layout, navigation and internal links.
- Provide a sitemap.xml, canonical URLs, RSS/Atom feed, robots guidance and appropriate structured data.
- Verify the site in search engine webmaster tools; request indexing and monitor coverage.
- **Search ranking or first-page placement is never guaranteed.** Search engines decide whether and where to index pages.

## Phase 3 — Updates and evidence gathering (not yet automated)

- Monitor permitted official RSS feeds, vendor release notes, government sources and reputable security advisories.
- Record original release date, event date, retrieval date and jurisdiction where relevant.
- De-duplicate articles and fact-check the primary sources before publication.
- Require editorial approval for disputed cybercrime and financial reporting.
- Never automatically run retrieved scripts or republish copyrighted news articles wholesale.

## Phase 4 — Google Drive backups (folder structure created)

- Store periodic repository exports and structured topic archive copies in the dedicated Google Drive backup folder.
- Preserve previous versions, media source credits, public/private separation and a change log.
- Configure a scheduled export/sync workflow separately; creating folders alone does not copy or continuously synchronize GitHub content.
